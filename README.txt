This project is a program that runs in a console window. It was made for Thekwini Metropolitan Libraries. The program helps manage library branches from one place using a Library Management System. The program lets library staff do lots of things like: manage library members, keep track of book loans. When they are returned, handle reservations, take payments, make branch reports, manage staff accounts and do things that involve branches.
The program uses simple ways to store data in the computer’s memory like Python dictionaries and lists. It shows how to use things like: functions to do tasks, Modular programming to keep the code organized, decision structures to make choices, loops to do things over and, over, dictionaries, lists and sets to store and organize data, input validation to make sure the data is and role-based access control to make sure staff members can only do what they are allowed to do
The Library Management System is a big part of this project. The Library Management System helps manage branches. The program is a console-based Python application. The console-based Python application is used to manage branches
The system has the following features:

  Staff Authentication
* A role-based login system for types of users
* The system has types of users including:
  - Librarian
  -Senior Librarian
  -System Administrator

  Member Management
* You can Register members in the system
* The system will Prevent duplicate SA IDs for members
* You can View member details in the system
* The system can Track loans and fines for members

  Book Loan Management
* You can Issue books to members
* The system can Process returns of books
* The system will Calculate fines for late returns
* The system will Validate borrowing eligibility for members
* The system will send Reservation notifications to members

  Fine Management
* The system allows for partial fine payments
* The system does fine calculations
* The system keeps a Payment history tracking for members

  Reporting
* The system generates Branch-level reports
* The system generates Overdue reports
* The system allows for Crossbranch comparisons
* The system provides Loan statistics

  Data Validation
* The system does ISBN validation for books
* The system does Date validation, for all entries
* The system does Menu input validation to prevent errors
* The system does Numeric validation to ensure data entry
